 ReleEasy Cloud - Registro de dependencias y tecnologias
================================================================================

Este archivo registra todas las herramientas, tecnologias y dependencias
utilizadas o instaladas durante el desarrollo del proyecto. Se actualiza en
cada fase. Formato de cada entrada:

  Nombre | Version | Ambito | Como se instalo / origen | Fecha | Notas

Ambitos: SISTEMA (herramienta global de la maquina), FRONTEND, BACKEND,
TERRAFORM, PIPELINE (CodeBuild / Step Functions), AWS (servicio en la nube),
SERVICIO EXTERNO (fuera de AWS) y DOCUMENTACION (memoria del TFM).
